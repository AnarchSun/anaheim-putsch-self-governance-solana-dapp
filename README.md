# 🏴 Anaheim / Anarcrypt – Call for Volunteer Builders

### TL;DR

We’re building **Anaheim**, an open-source Solana governance & social-media dApp with staking, mining, and DAO tooling.
It’s part of the **Deer Haul Putsch** soft-coup experiment: community-run government, not every-4-years voting.

We need **Solana / Anchor / React devs** to help ship the MVP.
Early contributors receive **R=3.57 tokens** + council roles + pooled-liquidity rewards.

---

## 🌌 Vision

* Replace “vote every 4 years” with **continuous wallet-based governance**.
* Community staking funds public ministries (health, roads, education) instead of banks.
* All code is MIT-licensed so anyone can fork for their own region.

---

## 🧩 Tech Stack

* **Solana + Anchor** on-chain programs (governance, liquidity-mining, timelock LP).
* **Next.js / React / TypeScript** frontend.
* **Realm.today** integration for DAO governance.
* **Raydium** liquidity pools.
* **NFT minter + profile pages** with reward mechanics.
* CRUD social features à la Reddit / Pi-Network.

---

## 👩‍💻 What We’re Building

* **Staking & Mining:** Users lock SOL or R=3.57 to earn governance power and rewards.
* **Proposal Engine:** Create and vote on custom program proposals.
* **Social Feed:** Posts, comments, and reputation points backed by on-chain accounts.
* **Liquidity Mining:** Free LP creation; bonus rewards for long-term stakers.

---

## 🎁 Incentives for Early Devs

* **Initial token grant** in R=3.57 (vested & must be held until liquidity grows).
* **10 % of raised liquidity** shared among key volunteers who bring liquidity providers.
* **Council governance token** = veto rights on protocol changes + admin roles on Discord/Telegram.
* **Raydium pool match:** I match USDT provided 1:1 so your LP earns double APR.

This is a volunteer start, but once staking revenue and liquidity scale, **paid roles** follow.
